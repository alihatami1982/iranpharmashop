========================================================================
                      پروژه فروشگاهی و داروخانه «ایران»
========================================================================

مقدمه:
پروژه «ایران» یک وب‌سایت فروشگاهی مدرن در حوزه آرایشی، بهداشتی و داروخانه است 
که به صورت کاملاً مستقل، امن و استاندارد توسعه داده می‌شود.

------------------------------------------------------------------------
۱. تکنولوژی‌ها و ابزارهای استفاده شده:
------------------------------------------------------------------------
- زبان برنامه‌نویسی: PHP (نسخه ۸ به بالا)
- پایگاه داده: MySQL / MariaDB (مدیریت شده از طریق PDO)
- فرانت‌اند: Bootstrap 5 (نسخه RTL)
- آیکون‌ها: Bootstrap Icons (کتابخانه مدرن آیکون‌های وب)
- محیط توسعه محلی: XAMPP
- امنیت: Prepared Statements، CSRF Protection، Sanitization، Validation، XSS Protection

------------------------------------------------------------------------
۲. ساختار پروژه و فایل‌ها:
------------------------------------------------------------------------
/iran
│
├── contact-us.php          # صفحه تماس با ما (فرم، اطلاعات تماس، نقشه گوگل)
├── process-contact.php     # اسکریپت پردازش امن فرم تماس و درج در دیتابیس
└── README.txt              # مستندات و راهنمای پروژه (همین فایل)

------------------------------------------------------------------------
۳. ساختار دیتابیس (MySQL):
------------------------------------------------------------------------
نام دیتابیس پیشنهادی: iran_db

جدول پیام‌های تماس (contact_messages):
- id (INT, Primary Key, Auto Increment)
- name (VARCHAR(100)) - نام و نام خانوادگی کاربر
- email (VARCHAR(100)) - ایمیل کاربر
- subject (VARCHAR(150)) - موضوع پیام
- message (TEXT) - متن پیام ارسال شده
- created_at (TIMESTAMP) - زمان ارسال پیام

دستور SQL ساخت جدول:
CREATE TABLE `contact_messages` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `name` VARCHAR(100) NOT NULL,
  `email` VARCHAR(100) NOT NULL,
  `subject` VARCHAR(150) NOT NULL,
  `message` TEXT NOT NULL,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

------------------------------------------------------------------------
۴. ملاحظات امنیتی پیاده‌سازی شده:
------------------------------------------------------------------------
- جلوگیری از SQL Injection: استفاده از PDO Prepared Statements و غیرفعال‌سازی Prepared Emulation.
- جلوگیری از XSS: استفاده از توابع پاکسازی و htmlspecialchars برای ورودی‌های کاربران.
- اعتبارسنجی دقیق (Validation): بررسی صحت ایمیل، حداقل طول کاراکترها برای نام و پیام.
- مدیریت خطای امن (Error Handling): جلوگیری از نمایش خطاهای پایگاه داده به کاربر و ثبت آن‌ها در Error Log سرور.

------------------------------------------------------------------------
۵. راهنمای اجرا روی لوکال (XAMPP):
------------------------------------------------------------------------
۱. پوشه پروژه را در مسیر htdocs سرور محلی (XAMPP) کپی کنید.
۲. کنترل پنل XAMPP را باز کرده و سرویس‌های Apache و MySQL را روشن کنید.
۳. از طریق مرورگر به آدرس phpMyAdmin وارد شده و دیتابیس `iran_db` را بسازید.
۴. دستور SQL مربوط به جدول `contact_messages` را در دیتابیس اجرا کنید.
۵. پروژه را از طریق آدرس زیر در مرورگر مشاهده کنید:
   http://localhost/iran/contact-us.php
