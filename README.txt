قالب صفحه اصلی سبزکالا - PHP + Bootstrap 5.3 RTL

نصب:
1) پوشه sabzkala-bootstrap را داخل ریشه وب‌سرور قرار دهید.
2) مطمئن شوید PHP روی سرور فعال است.
3) آدرس /sabzkala-bootstrap/index.php را باز کنید.

نیازمندی‌ها:
- PHP 7.4 یا بالاتر
- اتصال اینترنت برای بارگذاری Bootstrap، Bootstrap Icons، فونت و تصاویر CDN

فایل‌ها:
- index.php: ساختار صفحه و داده‌های نمونه محصولات و دسته‌بندی‌ها
- assets/css/style.css: استایل اختصاصی و رنگ سازمانی
- assets/js/app.js: تعاملات نمایشی سبد خرید، علاقه‌مندی و بازگشت به بالا

نکته:
نام سبزکالا، قیمت‌ها و محصولات نمونه هستند. برای استفاده عملی، اطلاعات را از دیتابیس بخوانید و سبد خرید/ورود/جستجو را به بک‌اند متصل کنید.
