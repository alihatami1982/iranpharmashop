بسیار عالی. برای اینکه سیستم MVC تو به درستی کار کند، ما به سه ستون اصلی نیاز داریم:
1.  **Database**: برای اتصال به MySQL.
2.  **Controller**: کلاس مادر که تمام کنترلرهای دیگر از آن ارث‌بری می‌کنند.
3.  **Router**: مغز متفکر سیستم که تشخیص می‌دهد کاربر چه صفحه‌ای را می‌خواهد (مثلاً `/product/5` یا `/admin/dashboard`).

بیا فایل‌ها را یکی‌یکی بسازیم.

### ۱. کلاس دیتابیس (`app/Core/Database.php`)
این کلاس از الگوی **Singleton** استفاده می‌کند تا در هر بار لود شدن صفحه، فقط یک بار به دیتابیس متصل شویم (برای بهینه‌سازی سرعت).

```php
<?php
// app/Core/Database.php

namespace App\Core;

use PDO;
use PDOException;

class Database {
    private static $instance = null;
    private $connection;

    private function __construct() {
        $config = require __DIR__ . '/../../config/config.php';
        try {
            $dsn = "mysql:host={$config['db_host']};dbname={$config['db_name']};charset={$config['db_charset']}";
            $this->connection = new PDO($dsn, $config['db_user'], $config['db_pass'], [
                PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES => false,
            ]);
        } catch (PDOException $e) {
            die("خطا در اتصال به دیتابیس: " . $e->getMessage());
        }
    }

    public static function getInstance() {
        if (self::$instance === null) {
            self::$instance = new self();
        }
        return self::$instance->connection;
    }
}
```

### ۲. کلاس کنترلر پایه (`app/Core/Controller.php`)
همه کنترلرهای تو (مثل `ProductController` یا `AdminController`) از این کلاس ارث‌بری می‌کنند تا بتوانند فایل‌های `view` را فراخوانی کنند.

```php
<?php
// app/Core/Controller.php

namespace App\Core;

class Controller {
    // متدی برای فراخوانی فایل‌های ویو (View)
    protected function render($view, $data = []) {
        // استخراج آرایه دیتا برای اینکه در فایل HTML مستقیم استفاده کنی
        extract($data);
        
        // مسیر ویو را مشخص می‌کنیم
        $viewPath = __DIR__ . '/../../views/' . $view . '.php';

        if (file_exists($viewPath)) {
            require_once $viewPath;
        } else {
            die("خطا: فایل ویو یافت نشد: " . $view);
        }
    }
}
```

### ۳. سیستم مسیریابی ساده (`app/Core/Router.php`)
در سیستم‌های حرفه‌ای، روتینگ پیچیده است، اما برای شروع، ما یک روت ساده می‌سازیم که آدرس را از URL بگیرد و به کنترلر مربوطه بفرستد.

```php
<?php
// app/Core/Router.php

namespace App\Core;

class Router {
    protected $routes = [];

    public function add($route, $controller, $method) {
        $this->routes[$route] = [
            'controller' => $controller,
            'method' => $method
        ];
    }

    public function dispatch($url) {
        $url = trim($url, '/');
        if (empty($url)) $url = 'home';

        if (array_key_exists($url, $this->routes)) {
            $controllerName = $this->routes[$url]['controller'];
            $methodName = $this->routes[$url]['method'];

            // ساختن نمونه از کنترلر
            $controller = new $controllerName();
            $controller->$methodName();
        } else {
            echo "<h1>404 - صفحه یافت نشد</h1>";
        }
    }
}
```

### ۴. فایل ورود اصلی (`public/index.php`)
حالا همه این‌ها را در نقطه شروع به هم متصل می‌کنیم.

```php
<?php
// public/index.php

// ۱. فعال‌سازی Autoloading برای کلاس‌های ما
spl_autoload_register(function ($class) {
    $prefix = 'App\\';
    $base_dir = __DIR__ . '/../app/';
    $len = strlen($prefix);
    if (strncmp($prefix, $class, $len) !== 0) return;
    $relative_class = substr($class, $len);
    $file = $base_dir . str_replace('\\', '/', $relative_class) . '.php';
    if (file_exists($file)) require $file;
});

use App\Core\Router;

// ۲. شروع روتینگ
$router = new Router();

// ۳. تعریف مسیرها (فعلاً برای تست)
// اینجا می‌گوییم اگر کاربر زد /home، برو به HomeController متد index
$router->add('home', \App\Controllers\HomeController::class, 'index');

// ۴. اجرای روتینگ بر اساس آدرس فعلی
$url = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
// اگر پروژه در زیرپوشه است، بخش اضافی URL را حذف کن
$basePath = '/iran_shop/public/'; 
$requestUri = str_replace($basePath, '', $url);

$router->dispatch($requestUri);
```

### گام بعدی چیست؟
تا اینجا "اسکلت" سایت ساخته شد. برای اینکه مطمئن شویم کار می‌کند، باید:
1.  یک کلاس `HomeController` ساده بسازیم.
2.  یک فایل ویو در `views/home.php` ایجاد کنیم.

**آیا می‌خواهی این دو مورد را با هم بسازیم تا اولین صفحه سایت "ایران" را روی مرورگر ببینی؟**

عالیه! انتخاب بسیار خوبی بود. برای ساخت **بخش مدیریت (Admin Panel)**، گام‌به‌گام به این شکل جلو می‌رویم:

1. **طراحی ساختار ادمین:** باید یک کنترلر جدید برای ادمین (`AdminController`) بسازیم تا مدیریت محصولات (افزودن، ویرایش، حذف) را کنترل کند.
2. **ساخت فرم افزودن محصول**: یک فرم HTML در پوشه `views/admin/` ایجاد می‌کنیم که مدیر بتواند نام، قیمت، دسته‌بندی و توضیحات محصول را وارد کند.
3. **ذخیره‌سازی در دیتابیس**: متد مربوطه را در مدل `Product` اضافه می‌کنیم تا اطلاعات ارسال شده را در جدول `products` ذخیره کند.

```php
    // متدی برای درج محصول جدید در دیتابیس
    public function create($data) {
```

### گام دوم: ساخت `AdminController`
یک فایل جدید به نام `AdminController.php` در پوشه `app/Controllers/` بساز و کدهای زیر را درون آن قرار بده:

```php
<?php
// app/Controllers/AdminController.php

namespace App\Controllers;

use App\Core\Controller;
use App\Models\Product;

class AdminController extends Controller {

    // نمایش لیست محصولات در پنل ادمین
    public function index() {
        $productModel = new Product();
        $products = $productModel->getAll();

        $this->render('admin/products/index', [
            'title' => 'مدیریت محصولات - پنل ادمین',
            'products' => $products
        ]);
    }

    // نمایش فرم افزودن محصول
    public function create() {
        $this->render('admin/products/create', [
            'title' => 'افزودن محصول جدید'
        ]);
    }

    // ذخیره محصول ارسالی از فرم
    public function store() {
        if ($_SERVER['REQUEST_METHOD'] === 'POST') {
            $data = [
                'name' => $_POST['name'] ?? '',
                'description' => $_POST['description'] ?? '',
                'price' => $_POST['price'] ?? 0,
                'category' => $_POST['category'] ?? '',
                'image' => 'default.jpg' // موقتاً عکس پیش‌فرض
            ];

            $productModel = new Product();
            $productModel->create($data);

            // بعد از ذخیره، برگرد به لیست محصولات ادمین
            header('Location: ' . BASE_URL . '/admin/products');
            exit;
        }
    }
}
```
*(نکته: حواست باشد اگر ثابت `BASE_URL` را در تنظیمات پروژه داری استفاده می‌کنی، مسیردهی‌ها بر اساس آن انجام می‌شود، یا می‌توانی روت نسبی بدهی).*

### قدم ۱: ساخت جدول دسته‌بندی‌ها در دیتابیس (phpMyAdmin)
اول باید یک جدول برای دسته‌بندی‌ها در دیتابیس `iran` بسازید. 
به phpMyAdmin بروید و یک جدول به نام `categories` با این ساختار بسازید:

*   `id`: INT (Primary Key, Auto Increment)
*   `name`: VARCHAR(255) (نام دسته‌بندی، مثل: "لوازم آرایشی", "مراقبت پوست")
*   `slug`: VARCHAR(255) (برای URLهای زیبا، مثل: `skin-care`)
*   `created_at`: TIMESTAMP (زمان ایجاد - اختیاری)

### قدم ۲: ساخت مدل دسته‌بندی (`app/models/Category.php`)
کلاسی برای ارتباط با جدول دسته‌بندی‌ها در دیتابیس:

```php
<?php
class Category {
    private $db;

    public function __construct() {
        $this->db = Database::connect(); // فرض بر این است که کلاس دیتابیس دارید
    }

    // گرفتن تمام دسته‌بندی‌ها
    public function getAll() {
        $stmt = $this->db->prepare("SELECT * FROM categories ORDER BY id DESC");
        $stmt->execute();
        return $stmt->fetchAll(PDO::FETCH_ASSOC);
    }

    // ذخیره دسته‌بندی جدید
    public function create($name, $slug) {
        $stmt = $this->db->prepare("INSERT INTO categories (name, slug) VALUES (?, ?)");
        return $stmt->execute([$name, $slug]);
    }

    // حذف دسته‌بندی
    public function delete($id) {
        $stmt = $this->db->prepare("DELETE FROM categories WHERE id = ?");
        return $stmt->execute([$id]);
    }
}
```

### قدم ۳: ساخت کنترلر دسته‌بندی‌ها (`app/controllers/Admin/CategoryController.php`)
این کنترلر درخواست‌های مربوط به لیست کردن، افزودن و حذف دسته‌بندی را مدیریت می‌کند:

```php
<?php
class CategoryController extends Controller {

    // نمایش لیست دسته‌بندی‌ها
    public function index() {
        $categoryModel = new Category();
        $categories = $categoryModel->getAll();

        $this->render('admin/categories/index', [
            'title' => 'مدیریت دسته‌بندی‌ها',
            'categories' => $categories
        ], 'admin/layouts/admin');
    }

    // پردازش فرم افزودن دسته‌بندی
    public function store() {
        if ($_SERVER['REQUEST_METHOD'] === 'POST') {
            $name = trim($_POST['name']);
            // ساخت slug ساده از روی نام (تبدیل به حروف کوچک و خط تیره)
            $slug = strtolower(trim(preg_replace('/[^A-Za-z0-9-]+/', '-', $name)));

            if (!empty($name)) {
                $categoryModel = new Category();
                $categoryModel->create($name, $slug);
            }
        }
        // بازگشت به صفحه لیست دسته‌بندی‌ها
        header('Location: ' . BASE_URL . '/admin/categories');
        exit;
    }

    // حذف دسته‌بندی
    public function delete($id) {
        $categoryModel = new Category();
        $categoryModel->delete($id);
        
        header('Location: ' . BASE_URL . '/admin/categories');
        exit;
    }
}
```

### ارتباط محصولات با دسته‌بندی‌ها (گام بعدی):
وقتی این بخش را پیاده کردید، برای اینکه هر محصول بفهمد متعلق به چه دسته‌بندی‌ای است، فقط کافی است یک ستون به نام `category_id` به جدول `products` در دیتابیس اضافه کنید و در فرم افزودن محصول، یک `<select>` از لیست دسته‌بندی‌ها بگذارید.

این ساختار را پیاده کنید؛ اگر در هر مرحله (مثل ساخت مدل یا روتینگ) سوالی داشتید بفرمایید تا دقیق‌تر بررسی کنیم.
